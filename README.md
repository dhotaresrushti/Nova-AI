# 🤖 Nova AI – Intelligent Voice Assistant

An intelligent AI-powered desktop voice assistant built using **Python**, **Speech Recognition**, **Natural Language Processing (NLP)**, and **Large Language Models (Ollama)**. Nova AI enables users to interact with their computer through natural voice commands, automate everyday tasks, perform web searches, manage files, launch desktop applications, and execute system operations using conversational AI.

---

## ✨ Key Features

### 🧠 AI & Conversational Intelligence
- Natural language conversations powered by Ollama LLM
- Speech-to-Text (STT) voice recognition
- Text-to-Speech (TTS) responses
- Intelligent command interpretation

### 💻 Desktop Automation
- Launch desktop applications using voice commands
- Perform Google searches instantly
- Open websites directly
- Execute system operations (Shutdown, Restart, Sleep)

### 📁 File & Folder Management
- Open files and folders
- Create new files and directories
- Manage basic file operations

### ⚡ Productivity
- Hands-free computer interaction
- Fast voice-based command execution
- Modular architecture for future feature expansion
